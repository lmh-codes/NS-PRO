## NS PRO v1.1.0

NodeSeek 非官方 Android 客户端，WebView 打开官网并本地注入 **Nodeseek Pro** 用户脚本，免装油猴。

### 本版更新

**冷启动与启动图**
- 启动图（Logo + 文案）持续显示至进度条出现，加载完成后与遮罩一起淡出进入主页
- WebView 在同色遮罩下加载，避免首帧黑闪与布局跳动
- 移除 Splash 固定 3 秒等待，预加载后立即进入 MainActivity

**下拉刷新**
- 修复列表/帖子页在非顶部时，长时间停留后慢速下拉仍误触发刷新的问题
- 顶部判断改为严格 scrollTop（≤ 8px），并记录手势起点，防止下拉过程中滚回顶部后误刷新

**后台会话（30 分钟）**
- 离开 App 30 分钟内回到前台：保留当前页与滚动位置，静默同步 @我 / 私信未读数
- 超过 30 分钟：列表页刷新论坛首页，帖子页刷新该帖第一页
- 从桌面图标进入已有任务时，不再强制跳回首页

**列表滚动**
- 修复冷启动后列表滚动位置异常、sessionStorage 误恢复导致沉底的问题

### 客户端能力

- 打开官方 NodeSeek，页面与官网一致
- 应用内检查更新、下载并安装
- 首次安装引导、长按菜单（刷新 / 重载脚本 / 清除登录）
- 外链走系统浏览器

**Android 7.0+** · 安装包见下方附件 `NS-PRO.apk`
