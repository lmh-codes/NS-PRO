## NS PRO v1.1.1

NodeSeek 非官方 Android 客户端，WebView 打开官网并本地注入 **Nodeseek Pro** 用户脚本，免装油猴。

### 本版更新

**快捷回复输入框**
- 修复点击头像后再点回复时，输入框过窄（宽度变量未定义导致缩成内容宽）的问题，恢复全宽显示

**Connect / 合作站**
- 修复浏览器式 Connect（`opener.location` / 关闭弹窗）授权成功后无法跳转到对应合作站的问题
- 缺 verify 包时仍跳转对应合作站，由合作站侧补齐登录

**跳转提醒顶栏**
- 点击左上角 X（及返回）整段关闭内嵌会话，不再只能一层一层关掉

**论坛左划返回**
- 帖子页左划优先回到最近访问的列表页；评论分页先回到该帖第一页
- 跳过历史栈中的旧帖、空间页、通知等，避免一路退回很早之前的帖子
- 限制深历史多步跳转，降低访问多帖后左划卡死的概率

### 客户端能力

- 打开官方 NodeSeek，页面与官网一致
- 应用内检查更新、下载并安装
- 首次安装引导、长按菜单（刷新 / 重载脚本 / 清除登录）
- 外链走系统浏览器

**Android 7.0+** · 安装包见下方附件 `NS-PRO.apk`
