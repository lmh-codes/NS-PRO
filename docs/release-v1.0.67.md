## NS PRO v1.0.67

NodeSeek 非官方 Android 客户端，WebView 打开官网并本地注入 **Nodeseek Pro** 用户脚本，免装油猴。

### 本版更新

- **跳转提醒顶栏**：左滑返回时顶栏保持「跳转提醒」，不再闪没或误显外链域名
- **论坛滚动**：修复页面上划偶尔卡住的问题
- **插件设置页**：修复滚到下方后无法下拉回顶、滚动中途卡顿的问题
- **快捷回复**：修复底部「发布评论」按钮被遮挡不可见
- **用户等级信息**：修复徽章展开弹层被截断、背景多余白边等问题

### 客户端能力

- 打开官方 NodeSeek，页面与官网一致
- 首次安装引导、长按菜单（刷新 / 重载脚本 / 清除登录）
- 外链走系统浏览器

### 内置 Pro 插件功能

用于增强 NodeSeek 论坛体验：

- **基础功能**：自动签到、签到过期提醒、下拉加载 / 无限滚动、NodeImage 图床上传助手
- **互动增强**：快速评论、快捷键操作
- **阅读体验**：Callout 渲染、代码高亮、图片预览、等级标记
- **内容管理**：内容过滤、浏览历史
- **个性化**：可视化设置面板，各功能可独立开关；支持配置备份
- **辅助工具**：名望诊断、社交关系相关辅助等

**Android 7.0+** · 安装包见下方附件 `NS-PRO.apk`
